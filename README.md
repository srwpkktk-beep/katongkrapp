# กระทงคร้าบบ — วิธีขึ้น GitHub

## ไฟล์ที่ต้องอัปโหลด
- `index.html` — ตัวเกม (ไฟล์เดียว รูป/เสียงฝังอยู่ในไฟล์ ~7 MB) → เปิดผ่าน GitHub Pages
- `server/` — เซิร์ฟเวอร์เก็บโคมลอย กระทง รูปประกวด และโหวต (Node 18+, ไม่ต้อง npm install)

## ตั้งค่าเซิร์ฟเวอร์ (ให้เห็นกระทงของทุกคน + หมดอายุ 24 ชม.)
1. รัน `node server/server.js` บนเซิร์ฟเวอร์ของคุณ (ตั้งค่าได้ด้วย `PORT`, `DATA_FILE`, `ALLOW_ORIGIN=https://ชื่อคุณ.github.io`)
2. เซิร์ฟเวอร์ต้องเป็น **https** (GitHub Pages เป็น https เรียก http ไม่ได้)
3. เปิด `index.html` หาบรรทัด `window.KR_API=""` ใส่ URL เซิร์ฟเวอร์ เช่น `window.KR_API="https://kratong.example.com"`
- โคมลอยและกระทงถูกลบอัตโนมัติหลัง 24 ชั่วโมง (ทั้งที่เซิร์ฟเวอร์และในเครื่องผู้เล่น) ส่วนรูปประกวดนาง/นายนพมาศไม่หมดอายุ
- แต่ละคนส่งโคม 3 / กระทง 3 / รูปประกวด 1 ต่อประเภท (ส่งใหม่จะแทนอันเก่า)

## เล่นกับเพื่อน
ใช้ห้องผ่าน PeerJS เหมือนเดิม ตอนนี้เห็นเป็ดของเพื่อนเดินในร้าน/สวนแบบเรียลไทม์ พร้อมชื่อและชุดที่ใส่

## ปุ่ม
E ทำ/ขาย (ที่แผงตลาดกด E ขายทีละชิ้น) · V คืนของเข้าลัง (เดินไปที่ลังของชิ้นนั้นแล้วกด V) · Space กระโดด

## จุดที่แก้เองได้ง่าย
- เสียงลูกค้าสั่ง: ตัวแปร `ORDV` ใน index.html (ชนิดกระทง → เสียง) ถ้าเสียงไหนไม่ตรงให้สลับชื่อ
- เหรียญเริ่มต้น: ตัวแปร `WAL` และ `money` (เริ่ม 2100)
